# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the affected repository's **Security** tab and
choose **Report a vulnerability**. Private vulnerability reporting is enabled on every addon repository.
Please do not open a public issue, pull request or discussion for a security problem.

Include the addon and version, what an attacker could do, and the steps or input that reproduce it.

## Scope

- The addons' Lua code as shipped in the release zip.
- The repositories' tools: data generators, test harnesses, CI workflows and release packaging.

Out of scope: the WoW: Forever client itself, Blizzard's servers, other addons, and the third-party
sites that host the release downloads. Report those to their owners.

## Supported versions

Only the latest release of each addon receives fixes.
